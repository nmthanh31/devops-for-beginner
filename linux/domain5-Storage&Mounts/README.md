# L05 — Linux Storage & Mounts

Bu domain học cách Linux nhận diện storage, tạo lớp filesystem và mount nó vào cây thư mục; sau đó chẩn đoán mount sai hoặc filesystem đầy.

## Theory

Đọc theo thứ tự trong [docs](./docs/README.md): block device/partition/filesystem → UUID và mount → bytes/inode → LVM → mount bền vững và recovery.

Hướng dẫn thao tác từng bước: [Persistent mount và LVM lab guide](./docs/06-persistent-mount-and-lvm-lab-guide.md).

Nội dung core đối chiếu LPIC-1 Topic 104; LVM được giới thiệu theo mức cơ bản của 102.1. Thao tác thay đổi partition, filesystem hoặc LVM chỉ thực hành trong VM/disk lab đã xác nhận.
