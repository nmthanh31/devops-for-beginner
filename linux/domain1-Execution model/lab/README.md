## Mục tiêu chung

Sau hai lab, cần làm được:

- tạo và quan sát process tree;
- xác định PID và PPID;
- đọc runtime state qua /proc;
- xác định executable và CWD;
- kiểm tra environment;
- xác định UID/GID;
- map process với FD, file và socket;
- phân biệt SIGTERM với SIGKILL;
- đọc exit code;
- viết transcript evidence cho một process thực tế.
