# Domain 4 — Identity & Permissions

Bu domain trả lời ba câu hỏi khi process truy cập file:

1. **Process là ai?** — UID/GID và group bổ sung.
2. **File thuộc về ai?** — owner/group và permission bits/ACL.
3. **Process đi qua được path không?** — quyền trên từng directory và file cuối.
